> ## Pull request overview
>
> This PR adds new FlyDSL fused kernels and integrates them into the gfx1250 grouped MoE path, aiming to reduce kernel launch count by fusing routing + MX quant + scatter + scale preshuffle (stage1) and fusing grouped quant + scale preshuffle (stage2). It also extends the gfx1250 grouped GEMM/gather-reduce stack to better support split-K and small-token performance, and updates tuning/config and tests accordingly.
>
> **Changes:**
> - Add fused FlyDSL kernels for (1) route+quant+scatter+scale-preshuffle and (2) grouped quant+scale-preshuffle, with Python wrappers exposed in `moe_kernels.py`.
> - Update gfx1250 grouped MoE pipeline to use the fused kernels on the fast path; extend gather-reduce to support split-K and configurable vector width.
> - Update warp-size detection for gfx1250, adjust split-K handling in mxscale GEMM, and refresh tuned grouped-MoE CSV entries; add a new correctness test.
