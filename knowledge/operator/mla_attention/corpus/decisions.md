### When splitting KV work, what information must the merge preserve?

**Card:** `attention-split-kv-merge` · **Type:** `performance_candidate` · **Evidence:** `source_observed`

**Axes:** `kv_partition`, `attention_semantics`, `numerical_contract`

#### Applicability

- `operator_families`: <code>attention_decode_paged</code>, <code>mla_attention</code>, <code>context_parallel_attention</code>
- `target_languages`: <code>triton</code>, <code>flydsl</code>, <code>gluon</code>

#### Use when

- A long KV sequence leaves too few independent query/head workgroups, or partial attention outputs already exist.

#### Try

- Try multiple KV partitions together with an explicit partial-output and normalization-statistics layout.
- Merge partials using their maxima and exponential sums, or the equivalent LSE representation; never take an unweighted average of already-normalized partial outputs.
- Include the merge and scratch traffic when assessing a split count, and mask unused partitions.

#### Rationale

- The Triton MLA reduce kernel rescales segment sums and outputs by exp2(segment_max - overall_max), then divides by the combined exponential sum.

#### Keep as alternatives

- Keep an unsplit path for short contexts or sufficiently large query batches.

#### Other implementations

- **flydsl** — The FlyDSL reducer consumes partial outputs, partial LSE and explicit partial/final maps; its host validator defines a separate ABI. [aiter_b3ad6c46:src_a6768ea282169992](source_evidence.md#aiter_b3ad6c46-src_a6768ea282169992)

### Which tensor and mapping invariants does the FlyDSL MLA reducer require?

**Card:** `attention-mla-reduce-abi` · **Type:** `constraint` · **Evidence:** `source_observed`

**Axes:** `implementation_contract`, `kv_partition`

#### Applicability

- `operator_families`: <code>mla_attention</code>, <code>attention_decode_paged</code>
- `target_languages`: <code>flydsl</code>

#### Use when

- The selected path calls flydsl_mla_reduce_v1 with mapped partial outputs.

#### Try

- Use FP32 partial_output [rows,H,Dv] and partial_lse [rows,H], int32 mapping/indptr arrays, and a common GPU device.
- Provide a 3D BF16/FP16 final output with packed last dimension and matching H/Dv; validate optional final LSE and final-map tensors too.
- Pass only valid split counts and map bounds, and preserve the difference between allocated maximum splits and actual splits.

#### Rationale

- The host validator checks dtype, rank, strides, shape relationships and split metadata before raw pointers reach the kernel.

#### Keep as alternatives

- Convert layouts explicitly at the boundary, accounting for their cost, or select a reducer that natively accepts the producer layout.
