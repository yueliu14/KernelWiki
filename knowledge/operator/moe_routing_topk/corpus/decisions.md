### When is the specialized HERD routing path a valid candidate?

**Card:** `moe-herd-routing-profile` · **Type:** `constraint` · **Evidence:** `source_observed`

**Axes:** `routing_semantics`, `implementation_contract`

#### Applicability

- `operator_families`: <code>moe_routing_topk</code>
- `target_languages`: <code>flydsl</code>

#### Use when

- A candidate intends to reuse the FlyDSL HERD sigmoid routing implementation.

#### Try

- Check the source's supported (score_func, experts, topk) profile instead of treating HERD as a generic top-k replacement.
- Preserve correction-bias scoring, candidate generation, final weight normalization and routed_scaling_factor as distinct parts of the contract.
- Honor the token-count, contiguous expert-column, output dtype/device and wave64 checks in _unsupported_reason.

#### Rationale

- The orchestration separates sigmoid-bias candidate selection from finalize, and publishes explicit narrow supported profiles.

#### Keep as alternatives

- Use the existing general routing implementation for unmatched profiles.

### Which outputs of expert sorting are part of the downstream GEMM ABI?

**Card:** `moe-sort-padding-sentinels` · **Type:** `constraint` · **Evidence:** `source_observed`

**Axes:** `expert_layout`, `implementation_contract`

#### Applicability

- `operator_families`: <code>moe_routing_topk</code>, <code>grouped_gemm_moe</code>, <code>fused_moe_grouped_gemm</code>
- `target_languages`: <code>flydsl</code>

#### Use when

- Token/expert routes are sorted and padded into expert-aligned work blocks.

#### Try

- Carry sorted token IDs, sorted route weights, sorted expert IDs and valid-count metadata together.
- Use the same unit_size for sorting/padding and downstream compute; preserve sentinel slots rather than interpreting padding as real routes.
- Size and initialize the sorting workspace according to token count, experts, top-k and alignment.

#### Rationale

- The sorting wrapper passes all four output structures and unit_size together; the kernel has explicit expert-block and sentinel-fill helpers.

#### Keep as alternatives

- Keep sorting separate from GEMM while validating a new expert layout.
