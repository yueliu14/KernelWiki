## mHC seam with following RMSNorm

**Before:** mHC delayed-pre/post processing leaves an explicit attn_norm/ffn_norm call.

**After:** Model checks HAS_AITER_MHC_FUSED_POST_PRE_DELAYED_RMS_NORM, supplies norm_weight, and skips the corresponding standalone norm on supported seams.

**Device language:** Python vLLM dispatch -> AITER fused-seam API. V06 historical AITER body and device language unavailable.

**Body change:** MHCPreDelayedOp can fold the preceding post block and following RMSNorm through mhc_fused_post_pre_delayed_rms_norm_aiter; model-entry broadcast remains an exception.

**Fusion:** Source verifies delegation of post/pre/norm to the fused AITER API and removal of the model-level norm call. Exact AITER internal launch count cannot be established from this upstream-only snapshot.

**Applicability:** MI355X/gfx950 ordinary vLLM path. No mono decode is enabled in these endpoint commands. Actual token rows and backend dispatch still determine the kernels executed. Requires available fused AITER seam and its shape guards; first 2-D entry broadcast does not fuse attn norm.

## MXFP4 sparse indexer and AITER sparse MLA

**Before:** Prior ROCm indexer/attention route and launch recipe.

**After:** CLI explicitly requests indexer_kv_dtype=mxfp4 and indexer_sparse_logits=true; ROCm MXFP4 indexer dispatches to AITER cache/query producers.

**Device language:** Python wrappers calling AITER Triton cache/RoPE/quantization ops; historical dependency bodies unavailable.

**Body change:** Adds DeepseekV41RocmMxfp4Indexer, rocm_mxfp4_indexer_k_store and rocm_mxfp4_indexer_q_quant; uses k_norm_rope_mxfp4_cache and q_rope_mxfp4_quant APIs.

**Fusion:** Indexer norm/RoPE/quant/cache contracts are fused producer APIs; sparse scoring, top-k, attention and wo_a remain separate stages. Do not infer a whole indexer/attention fusion.

**Applicability:** MI355X/gfx950 ordinary vLLM path. No mono decode is enabled in these endpoint commands. Actual token rows and backend dispatch still determine the kernels executed. New endpoint attention-config and VLLM_ROCM_USE_AITER_TRITON_SPARSE_MLA enable the relevant selection; KV transfer/other guards can change fallback.
